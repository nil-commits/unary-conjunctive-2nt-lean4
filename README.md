# Optimal 2-Nonterminal Unary Conjunctive Grammars for $\{a^{4^n}\}$ and $\{a^{2^n}\}$ in Lean 4

> **Scope Note:** Alexander Okhotin's general bounded nonterminal complexity problem—whether there exists a universal constant $k$ such that every Boolean-grammar language admits a Boolean grammar with at most $k$ nonterminal symbols—**remains open**, even over a unary alphabet. This repository formalizes exact $k=1$ vs. $k=2$ results and a 2-nonterminal stretched-collapse theorem for binary-normal-form unary grammars.

## Summary of Formalized Results

All theorems in [`RHDirect/PPL153_UnaryNonterminalOptimal.lean`](RHDirect/PPL153_UnaryNonterminalOptimal.lean) are proved in Lean 4 (`v4.33.1`) over Mathlib with zero `sorry` and zero custom axioms:

1. **Optimal 2-nonterminal unary conjunctive grammars for $\{a^{4^n}\}$ and $\{a^{2^n}\}$**
   - `grammarFourPow`: an explicit **2-nonterminal**, $\varepsilon$-free, negation-free unary conjunctive grammar (14 rules) generating $\{a^{4^n} : n \ge 0\}$, improving A. Jeż's 2007 4-nonterminal conjunctive grammar to 2 nonterminals.
   - `grammarTwoPow`: an explicit **2-nonterminal**, $\varepsilon$-free, negation-free unary conjunctive grammar (20 rules) generating $\{a^{2^n} : n \ge 0\}$.
   - Verified under **both** Okhotin's strongly-unique Boolean semantics (`grammarFourPow_generates`, `grammarTwoPow_generates`) and standard textbook least-fixed-point (LFP) conjunctive semantics (`grammarFourPow_generates_lfp`, `grammarTwoPow_generates_lfp`).

2. **Unconditional 1-nonterminal lower bounds for $\{a^{B^n}\}$ ($B \ge 2$)**
   - `no_one_nt_pow_language`: for every integer $B \ge 2$, no 1-nonterminal unary Boolean grammar (with arbitrary finite rules, conjunctions, negations, $\varepsilon$-rules, and unit rules) generates $\{a^{B^n} : n \ge 0\}$ under strongly-unique semantics.
   - `no_one_nt_pow_language_lfp`: for every $B \ge 2$, no 1-nonterminal unary conjunctive grammar (allowing arbitrary $\varepsilon$-rules and unit rules such as $S \to S$) generates $\{a^{B^n} : n \ge 0\}$ under standard LFP semantics.
   - Together with (1), `exact_nt_complexity_two_pow_and_four_pow` and `exact_nt_complexity_two_pow_and_four_pow_lfp` establish that the exact nonterminal complexity of both $\{a^{4^n}\}$ and $\{a^{2^n}\}$ is **2** under both semantics.

3. **General 2-nonterminal stretched collapse via $B_4$ Sidon sets**
   - `stretched_collapse_2nt` and `exists_stretch_modulus_2nt`: for any $m$-nonterminal $\varepsilon$-free unary grammar `G : UnaryBNFGrammar m` in Binary Normal Form generating $L \subseteq \mathbb{N}_{>0}$, and any valid $B_4$ Sidon configuration $(M, r)$ of size $m + 2$ modulo $M$ (always guaranteed by `base5_isValidB4Config` with $M = 5^{m+3}$ and $r_i = 5^{m+2} + 5^i$), the stretched language $M \cdot L = \{a^{Mn} : a^n \in L\}$ is generated by an explicit 2-nonterminal unary Boolean grammar `stretchedCollapseGrammar G M r` (which is conjunctive whenever `G` is conjunctive).
   - *Explicit caveat:* `stretched_collapse_2nt` and `exists_stretch_modulus_2nt` take a grammar already in $\varepsilon$-free Binary Normal Form (`UnaryBNFGrammar m`) directly; the standard conversion from an arbitrary $\varepsilon$-free unary Boolean or conjunctive grammar to Binary Normal Form (Okhotin 2001, 2004) is **not** separately formalized in this file.

4. **Unary restriction lemma (`unary_restriction_theorem`)**
   - For any alphabet $\Sigma$, symbol $a \in \Sigma$, and $k$-nonterminal Boolean (resp. conjunctive) grammar $G$ generating $K \subseteq \Sigma^*$, the unary slice $\{n : a^n \in K\}$ is generated by a $k$-nonterminal unary Boolean (resp. conjunctive) grammar `restrictToChar G a`.

## Explicit Grammar Rules (`grammarFourPow` and `grammarTwoPow`)

Both grammars use two nonterminals $N = \{S, X\}$, start symbol $S$, terminal alphabet $\Sigma = \{a\}$, no $\varepsilon$-rules, no unit rules, and no negation, derived from the $B_4$ Sidon vector $r = [22, 23, 27, 43]$ modulo $M = 256$:

**Shared rules for $X$ (`jezXRules`, 8 rules):**
$$
\begin{aligned}
X &\to a^{234} \mid a^{489} \mid a^{741} \mid a^{1493} \\
X &\to (a^{27} X X \mathbin{\&} a^{24} X X) \mid (a^{21} X X \mathbin{\&} a^{43} X X) \mid (a^{18} X X \mathbin{\&} a^{59} X X) \mid (a^{11} X X \mathbin{\&} a^{2} X X)
\end{aligned}
$$
*(The intended language of $X$ is $\{a^{256 \cdot 4^k - 22}\} \cup \{a^{256 \cdot 2 \cdot 4^k - 23}\} \cup \{a^{256 \cdot 3 \cdot 4^k - 27}\} \cup \{a^{256 \cdot 6 \cdot 4^k - 43}\} : k \ge 0$.)*

**`grammarFourPow` (2 nonterminals, 14 rules total, $L(S) = \{a^{4^n} : n \ge 0\}$):**
$$
S \to a \mid a^4 \mid a^{16} \mid a^{64} \mid a^{256} \mid (a^{49} X X \mathbin{\&} a^{46} X X)
$$
together with the 8 rules for $X$.

**`grammarTwoPow` (2 nonterminals, 20 rules total, $L(S) = \{a^{2^n} : n \ge 0\}$):**
$$
S \to a \mid a^2 \mid a^4 \mid a^8 \mid a^{16} \mid a^{32} \mid a^{64} \mid a^{128} \mid a^{256} \mid a^{512} \mid (a^{49} X X \mathbin{\&} a^{46} X X) \mid (a^{44} X X \mathbin{\&} a^{66} X X)
$$
together with the 8 rules for $X$.
